# 📄 MultiAgentCom：下一代多智能体协同开发平台

**项目代号:** MultiAgentCom
**核心架构师:** Obsidian
**系统定位:** 基于主群架构 (Manager-Worker MAS)、具备深度人类在环 (HITL) 与时空版本控制的商业级全自动软件研发平台。

## 一、 核心架构与技术底座

MultiAgentCom 摒弃了传统的“单发单收”大模型对话模式，采用**“主控调度 + 专职打工”**的动态路由编排架构。

* **动态路由与造人机制 (Dynamic Routing):** 主 Agent 根据需求复杂度，动态实例化特定技术栈的子 Agent（如精通高并发的 Go-Agent、负责数据清洗与逆向的 Python-Agent、负责交互的 Vue-Agent 等），按需组建虚拟开发团队。
* **AI 内部通信协议 (Token 压缩机制):** 核心技术壁垒之一。Agent 之间剔除人类自然语言的“废话”，采用极简标识、向量或定制 XML/JSON 进行高频结构化通信（如 `[Python->Go] SYNC_SCHEMA_V2(json_hash:8f9a)`），极大地降低 Token 消耗并遏制“幻觉”与“遗忘”。

## 二、 全生命周期工作流

系统将模糊的人类想法转化为标准工程代码，遵循“单一事实来源 (SSOT)”原则。

1.  **需求反刍与 PRD 生成:** 用户（人类）输入初始需求，主控架构师 Agent 通过连环追问填补逻辑漏洞，最终生成一份严谨的需求规格说明书 (PRD)。
2.  **核心契约缔结:** 主 Agent 在系统内部率先定义标准 API 文档与数据结构（如 OpenAPI/Swagger）。这是多 Agent 协同的“契约”，确保前后端分离开发时严丝合缝。
3.  **精准上下文分发 (Context Injection):** 主 Agent 将几万字的全局文档进行精准切片，只把 Go-Agent 需要的路由契约、Vue-Agent 需要的 UI 规范分发下去，避免子 Agent 脑容量过载。

## 三、 双层沙盒物理隔离机制

采用类似操作系统的进程隔离与共享内存机制，确保开发过程的绝对安全与整洁。

* **私有沙盒 (Private Sandbox - vmp/tmp):** 每个子 Agent 的“无尘车间”。Agent 在此进行依赖安装、试错、打印脏日志或运行风险脚本。崩溃只影响单体，不污染主干。
* **共享沙盒 (Shared Sandbox - 产物仓库):** 唯一的真理仓库。子 Agent 在私有沙盒测试通过后，将代码打包为制品 (Artifact) 提交合并。任何集成测试失败，共享沙盒可瞬间回滚，并将错误打回重做。

## 四、 终极控制权：深度人类在环 (HITL)

系统提供了远超常规 AI 框架的“上帝视角”，允许开发者在任意节点接管核心逻辑。

* **非阻塞式需求注入 (Staging & Checkpointing):** 面对突发的需求变更，系统不会强行中断正在编码的 Agent，而是建立“影子分支”。等待 Agent 运行到安全节点（逻辑闭环）后，通过精准的 Context Diff 将新需求增量注入。
* **动态纠偏 (Context Steering):** 随时打断钻牛角尖的 Agent，通过高优先级指令强控其思维链 (CoT)，调整研发方向。
* **状态覆盖与物理加锁:** 开发者可直接进入沙盒，手写核心代码并拍入系统。系统利用 AST 解析或注释标签（如 `# [LOCKED BY HUMAN]`）对其进行物理级锁定。这部分代码将被系统视为“绝对真理 (Ground Truth)”，强制要求 Agent 以此为锚点进行外围逻辑补全与模仿学习。

## 五、 时空穿梭与版本控制 (Time Machine)

将 Git 的灵魂与 AI 上下文记忆深度结合，提供零成本试错的时间机器。

* **细粒度语义快照:** 系统在每个逻辑闭环、集成测试点或人类干预点自动打下快照。
* **平行宇宙分支:** 回滚操作不会直接销毁未来，而是开启一条新时间线。开发者可随时在“原版”和“新版”之间穿梭对比。
* **记忆剥离重组:** 发生时空回滚时，主 Agent 会向全系统广播，强制擦除所有子 Agent 大脑中属于“废弃未来”的短期记忆，确保逻辑绝对同步。

## 六、 商业级监控与全景可视化

告别黑盒开发，提供极致的透明度与信任感。

* **状态矩阵面板:** 实时监控每个 Agent 的存活状态（🟢 疯狂输出 / 🟡 查阅文档 / 🔴 阻塞报错 / ⚪️ 空闲）。
* **依赖拓扑流水线:** 动态展示 Agent 之间的数据流转与提交流程（如 Manager -> Go -> QA）。
* **内部 Token 终端:** 滚动展示 Agent 间的“黑话”通信日志，随时掌握底层算力流向。

## 七、 沉浸式验收与工程化交付

“所见即所得，满意再提车”的最终闭环。

* **内部预览服务 (Live Preview):** 代码在沙盒内编写完毕后，系统自动拉起集成测试环境，利用内部反向代理在界面内嵌 IFrame 窗口。开发者可直接进行交互点击与功能验收，并支持修改代码后的热更新 (Hot Reload)。
* **标准化打包:** 验收通过后，系统自动生成完整的工程化依赖（如 `go.mod`, `package.json`）、跨平台一键部署脚本 (`docker-compose.yml`) 以及详细的 `README.md`，输出干净、可直接投入生产的源码压缩包。
